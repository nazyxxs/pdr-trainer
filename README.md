# ПДР Тренажер

Безкоштовний тренажер тестів ПДР України на основі **офіційної бази питань ГСЦ МВС**
(наказ від 29.10.2025 № 225): 2332 питання, 65 розділів, 1123 ілюстрації.

made by **nazyxxs**

## Можливості

- **Іспит** як у сервісному центрі: 20 питань, 20 хвилин, до 2 помилок
  (10 ПДР + 4 безпека + 4 будова ТЗ + домедична допомога + право).
- **Теми**: будь-який розділ окремо, прогрес-бар для кожного.
- **Мої помилки**: повторення питань, де остання відповідь була неправильна.
- **Нові питання** / **Тренування**: 20 питань з одразу видимою правильною відповіддю.
- **Статистика**: % засвоєних питань, % переглянутої бази, графік іспитів, слабкі теми.
- Категорії A, B, C, D, BE/CE/DE, T.
- Темна / світла тема, працює на телефоні, можна встановити як додаток (PWA), працює офлайн.
- Прогрес зберігається в браузері; між пристроями переноситься через **Налаштування → Перенести прогрес**.

## Запуск

Потрібен Node.js 20+.

```bash
npm install
npm run dev
```

Відкрий адресу з терміналу (наприклад `http://localhost:5173`).
`npm run dev` запускається з `--host`, тому з телефона в тій самій Wi-Fi мережі
можна відкрити адресу `Network: http://192.168.x.x:5173`.

Збірка для публікації: `npm run build` (результат у папці `dist/`).

## Акаунти і синхронізація (Supabase, безкоштовно)

Без налаштування сайт працює як раніше: прогрес лише в браузері.
Щоб з'явились акаунти і прогрес був однаковий на всіх пристроях:

1. Зареєструйся на https://supabase.com і створи новий проєкт (план Free, регіон Europe).
2. **SQL Editor → New query** → встав вміст `supabase/schema.sql` → **Run**.
3. **Authentication → Sign In / Providers → Email**: для простоти можна вимкнути
   **Confirm email** (тоді реєстрація працює без листа на пошту).
4. **Authentication → URL Configuration → Site URL**: адреса сайту
   (локально `http://localhost:5173`, потім адреса з GitHub Pages).
5. Скопіюй `.env.example` у `.env.local` і встав **Project URL** та **anon (publishable) key**
   (кнопка **Connect** або **Project Settings → API**).
6. Перезапусти `npm run dev` - на головній з'явиться кнопка **Увійти**.

Як це працює: прогрес завжди пишеться в localStorage (працює офлайн), а після входу
`src/sync.js` раз на ~2 секунди після змін відправляє його в таблицю `progress`
і підтягує зміни, коли повертаєшся на вкладку. Конфлікти між пристроями вирішуються
по кожному питанню окремо: перемагає новіша відповідь. Anon key можна тримати
у фронтенді - доступ до даних захищено Row Level Security (кожен бачить лише свій рядок).

## Публікація на GitHub Pages (безкоштовно)

1. Створи репозиторій на GitHub і запуш туди проєкт.
2. Скопіюй `deploy/github-pages.yml` у `.github/workflows/deploy.yml`.
3. У репозиторії: **Settings → Pages → Source: GitHub Actions**.
4. Якщо налаштовані акаунти: **Settings → Secrets and variables → Actions → Variables**,
   додай `VITE_SUPABASE_URL` і `VITE_SUPABASE_ANON_KEY`.
5. Після пушу в `main` воркфлоу збере і опублікує сайт
   за адресою `https://<твій-логін>.github.io/<назва-репозиторію>/`.
   Цю адресу додай у Supabase: **Authentication → URL Configuration** (Site URL / Redirect URLs).

## Як отримано дані

| Файл | Що робить |
|---|---|
| `source/*.pdf` | офіційні PDF з https://hsc.gov.ua/pitannya-ta-ispit-z-pdr/ (не комітяться) |
| `tools/parse_questions.py` | PDF з питаннями → `data/questions_raw.json` + картинки в `public/img/` |
| `tools/parse_answers.py` | скан таблиці відповідей → клітинки та гліфи цифр (OpenCV) |
| `tools/build_data.py` | зводить питання і відповіді → `public/questions.json` |

Таблиця відповідей - це скан, тому цифри розпізнано класифікатором гліфів (кластеризація
+ ручна розмітка кластерів), а останню бліду сторінку переписано вручну
(`data/answers_page11_manual.json`). Перевірки: кількість відповідей збігається з кількістю
питань (2332), жодна відповідь не виходить за межі кількості варіантів, вибірково звірено зі сканом.
Дві клітинки скану нечитабельні, відповіді для них встановлено за змістом питання
(`INFERRED` у `tools/build_data.py`, обидва питання - категорія D).

Коли ГСЦ оновить базу: поклади нові PDF у `source/` і виконай

```bash
pip install pymupdf opencv-python numpy
python tools/parse_questions.py
python tools/parse_answers.py
python tools/build_data.py
```

(для нового скану відповідей кластери в `build_data.py` треба буде перепідписати).
