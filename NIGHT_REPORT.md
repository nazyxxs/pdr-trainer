## Оптимізація

- **Швидший перший запуск:** база питань (178 КБ у стиснутому вигляді) тепер починає вантажитись одразу,
  паралельно з кодом сайту, а не після нього (`index.html`, `<link rel="preload">`). Перевірено: файл качається один раз.
- **Розглянув і відхилив** розбиття коду на частини: економія лише ~8 КБ (10%), але після кожного деплою
  вкладка, відкрита раніше, могла б не завантажити екран статистики чи друзів. Не варте ризику.
- Розмір сайту: 91 КБ JS + 4 КБ CSS у стиснутому вигляді - для такого застосунку це нормально.

## Що зробити тобі

1. **Supabase → SQL Editor → New query**, виконай по черзі:
   - вміст `supabase/progress_merge.sql` (захист прогресу на сервері, баг №3);
   - останній блок `supabase/social.sql` - функцію `server_now()` (баг №2):
     ```sql
     create or replace function public.server_now()
     returns timestamptz language sql stable as $$ select now() $$;
     grant execute on function public.server_now() to authenticated;
     ```
   Без цих двох кроків сайт теж працює, просто без цих двох захистів.
2. **Запуш:**
